Three capture modes, instant streaming answers, zero setup beyond your API key.

📄
Full Page Capture

Automatically extracts all visible text from any webpage the moment you open the extension. Works on articles, docs, dashboards, anything.

✂️
Text Selection

Highlight any text on the page and ask questions about just that selection. Perfect for specific paragraphs, code snippets, or confusing sentences.

📸
Screenshot Mode

Captures a visual screenshot of your visible browser tab and sends it to a vision-capable model. Great for charts, images, and visual content.

⚡

Responses stream in real-time word by word using Groq's ultra-fast inference — no waiting for the full answer to load.

// get started

Install in 5 minutes

No Chrome Web Store needed. Load it directly from your computer.

01
Get a free Groq API key

Visit console.groq.com, sign up for free, and create an API key. Groq offers a generous free tier — no credit card required to start.

02
Download the extension

Click the ⚡ Download Extension button above, or go to the GitHub Releases page and download the latest extension.zip file.

03
Extract the ZIP file

Right-click the downloaded extension.zip and choose Extract All. You'll get a folder — open it and find the extension/ subfolder inside.

04
Load into Chrome

Open Chrome and go to chrome://extensions/. Toggle on Developer Mode in the top-right corner. Click Load unpacked and select the extension/ folder (the one containing manifest.json).

05
Enter your API key & go!

Click the Groq Screen AI icon in your Chrome toolbar. Paste your Groq API key in the API KEY field and click Save. Navigate to any page and start asking questions! ⚡
